# FastAPI Calculator - Module 8

Repository: https://github.com/hrief/module8_is601

A browser calculator with addition, subtraction, multiplication, and division.
The arithmetic implementation lives in `app/operations/__init__.py` (the starter project uses a package instead of a standalone operations.py).

## Run locally

Use Python 3.11 for the same version as CI.

```powershell
python -m venv .venv
.venv/Scripts/Activate.ps1
python -m pip install -r requirements.txt
python -m playwright install chromium
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

Open http://127.0.0.1:8000. On macOS/Linux activate with `source .venv/bin/activate`.
On Linux, install browser system dependencies with `python -m playwright install --with-deps chromium`.

## Tests

```sh
python -m pytest
python -m pytest tests/unit
python -m pytest tests/integration
python -m pytest tests/e2e
```

- Unit tests cover every arithmetic operation, signs, zero, fractions, and operation/error logs.
- Integration tests cover the homepage and every arithmetic endpoint, invalid or missing input, malformed JSON, overflow, and unexpected failures.
- Playwright tests exercise all four buttons, division by zero, recovery, and empty inputs against an isolated live server. Assertions wait for the UI result.
- Coverage includes both the operations package and main.py; the HTML report is in `htmlcov/index.html`.

Successful calculations are logged at INFO. Invalid requests and arithmetic failures are logged with their details; unexpected failures include a traceback and return a generic HTTP 500 response. Non-finite inputs and results are rejected with HTTP 400.
